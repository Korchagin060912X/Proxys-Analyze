# Проверка MTProto-прокси

Консольная программа проверяет прокси из `listOfProxy.json`: через каждый
прокси отправляется MTProto-запрос `req_pq`, а рабочим считается прокси,
вернувший ожидаемый ответ Telegram. В `ProxyWorks.txt` записываются до 20
рабочих прокси с наименьшим временем ответа.

## Установка и запуск

```text
python -m pip install -r requirements.txt
copy listOfProxy.example.json listOfProxy.json
python check_proxies.py
```

Файлы находятся рядом со скриптом, поэтому запускать его можно из любой
текущей папки. Таймаут проверки одного прокси можно задать отдельно:

```text
python check_proxies.py --timeout 8
```

## Формат списка

`listOfProxy.json` поддерживает как JSON-массив прокси:

```json
[
  {
    "hostname": "hostname",
    "port": 443,
    "type": "MTPROTO",
    "secret": "0123456789abcdef0123456789abcdef"
  }
]
```

Безопасный пустой шаблон находится в `listOfProxy.example.json`. Создайте
локальный `listOfProxy.json` по этому шаблону и добавьте свои данные прокси.
Локальный список и результаты проверки исключены из Git, потому что могут
содержать секреты подключения.

Для нескольких прокси добавьте несколько объектов в массив. Поле `type`
необязательное; если указано, его значение должно быть `MTPROTO`. Для имени
сервера также можно использовать поле `host` или `server`. Секрет должен
содержать 32 hex-символа; поддерживаются также секреты с префиксом `dd` и
последующими 32 hex-символами. TLS-секреты с префиксом `ee` не поддерживаются.

Также можно использовать JSON-экспорт Telegram: программа найдёт ссылки
`https://t.me/proxy?...` в сообщениях и кнопках, удалит повторяющиеся прокси
и проверит найденные адреса.

В `ProxyWorks.txt` для каждого рабочего прокси сохраняются данные и готовая
ссылка `https://t.me/proxy?...`. Откройте ссылку на устройстве с Telegram,
чтобы добавить прокси:

```text
# hostname port MTPROTO secret ping=... ms
https://t.me/proxy?server=hostname&port=443&secret=...
```
